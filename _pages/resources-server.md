## About the Server

We recently started working on a new server: Helios. This is the place where you can access imaging data and should perform all your analyses. To request an account, please add your Amsterdam UMC email address to [this](https://amsterdamumc.sharepoint.com/sites/Div5_TeamNeuropsychiatry_SWG/Gedeelde%20documenten/General/Helios/Helios_accounts.xlsx?d=w00720a435740417893993d286094a963&csf=1&web=1&e=FqsFjb) list and notify your supervisor. You can find all information on how to work on this server on the [Helios User Wiki](https://hg-aumc.gitlab.io/hpc-aumc/user-wiki/).

If you are not familiar with working in a Linux environment, it may be helpful to do an [Introduction to Shell course](https://www.datacamp.com/courses/introduction-to-shell). See the [Datacamp recources](./resources-datacamp.md) for more information.
